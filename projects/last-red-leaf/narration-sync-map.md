# 《最后一片红叶》旁白—画面同步表

## Scene 01 · 0–11.65 秒

- 画面锚点：深秋环境建立 → 水洼显露 → 冷风与红叶庇护 → 红叶下远望。
- 旁白：小蜗牛走到宽宽的水洼前。冷风吹来，最后一片红叶低下身子，像小屋一样，为它挡住寒意。
- 实测旁白时长：10.296 秒；从 0.35 秒开始，约 10.65 秒结束。
- 技术收尾：1.0 秒，用于红叶轻颤、蜗牛远望与转幕，不用静止帧补足初始估算。
- 放置起点：本幕 0.35 秒。

## Scene 02 · 11.40–26.13 秒（含 0.25 秒转场重叠）

- 画面锚点：强风掀叶 → 红叶落水 → 蜗牛登船 → 向右渡越 → 暖岸停靠。
- 旁白：忽然，一阵大风把红叶吹进水里。红叶没有远去，它变成一只小船，载着小蜗牛，慢慢驶向温暖的彼岸。
- 实测旁白时长：13.056 秒；从本幕 0.25 秒开始，约 13.31 秒结束。
- 技术收尾：1.4 秒，用于抵岸、光路和载体缓停；第二幕与第一幕重叠淡化 0.25 秒。
- 放置起点：本幕 0.25 秒。
